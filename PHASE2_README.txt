PHASE 2 - LESSON ENGINE

1. Dừng npm run dev bằng Ctrl+C.
2. Giải nén gói Phase 2.
3. Chép TOÀN BỘ nội dung bên trong folder hanyu-learning-phase2 vào folder project hiện tại.
4. Chọn Replace the files in the destination.
5. Không cần xóa node_modules.
6. Chạy npm run dev.

Kiểm tra:
- Trang chủ có nút “Mở bài demo”.
- Giáo trình > Quyển 1 > Bài 1 mở được.
- Tab Bài khóa hiển thị Trung/Pinyin/Việt.
- Bấm 你好 / 我 / 学生 mở popup.
- Tab Từ vựng có 3 card.
- Nút 🔊 dùng TTS tiếng Trung.
- Tab Ngữ pháp hiển thị A 是 B.

Dữ liệu này chỉ là DEMO kỹ thuật, không phải nội dung chính thức của sách.
