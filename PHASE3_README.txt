PHASE 3 – CONTENT VIEW

Cách cập nhật:
1. Dừng npm run dev bằng Ctrl+C.
2. Giải nén hanyu-learning-phase3.zip.
3. Mở folder hanyu-learning-phase3.
4. Copy toàn bộ nội dung bên trong.
5. Dán đè vào project hiện tại hanyu-learning.
6. Chọn Replace the files in the destination.
7. Không xóa node_modules.
8. Trong VS Code chạy:
   npm run dev

Kiểm tra:
- Trang chủ > Mở bài demo.
- Tab Bài khóa:
  + có Mục tiêu
  + có Hội thoại theo người nói A/B
  + có nút ẩn/hiện Pinyin
  + có nút ẩn/hiện Tiếng Việt
  + bấm 你好 / 我 / 学生 mở popup
  + từng câu có nút nghe
- Tab Từ vựng vẫn hoạt động.
- Tab Ngữ pháp:
  + hiển thị pattern
  + giải thích
  + ghi chú
  + nhiều ví dụ
  + từng ví dụ có nút nghe.

Dữ liệu Phase 3 vẫn là DEMO kỹ thuật.
Không coi nội dung demo là bản chép chính thức của sách.
