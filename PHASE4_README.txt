PHASE 4 – QUIZ / FLASHCARD / LISTENING

CÁCH CẬP NHẬT
1. Dừng server bằng Ctrl+C.
2. Giải nén hanyu-learning-phase4.zip.
3. Mở folder hanyu-learning-phase4.
4. Copy toàn bộ nội dung bên trong.
5. Dán đè vào project hiện tại:
   C:\Users\admin\Downloads\hanyu-learning
6. Chọn Replace files.
7. Không xóa node_modules.
8. Chạy:
   npm run dev

KIỂM TRA

A. Ôn tập
- Menu Ôn tập.
- Có các loại:
  Hán → nghĩa
  Nghĩa → Hán
  Hán → Pinyin
  Pinyin → Hán
  Nghe → Hán
  Nghe → nghĩa
- Chọn đáp án có phản hồi đúng/sai.
- Có điểm.

B. Flashcard
- Menu Thẻ.
- Bấm card để lật.
- Có Hán tự, Pinyin, nghĩa, Hán Việt.
- Có nút nghe.
- Có 4 nút Quên / Khó / Nhớ / Rất dễ.
- Phase 4 CHƯA lưu SRS; Phase 5 mới lưu.

C. Luyện nghe
- Menu Luyện nghe ở sidebar desktop.
- Nghe từng câu.
- Chữ Hán ẩn mặc định.
- Có nút hiện/ẩn chữ Hán và nghĩa.

D. Trong Lesson
- Tab Ôn tập đã chạy Quiz Engine.

LƯU Ý
Dữ liệu vẫn là demo kỹ thuật Phase 2–4.
Dữ liệu sách thật sẽ được xử lý và tích hợp ở Phase 8.
