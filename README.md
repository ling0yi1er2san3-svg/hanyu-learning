# Hán Ngữ Learning — Phase 1

## Chạy local

Yêu cầu: Node.js LTS.

```bash
npm install
npm run dev
```

Mở URL Vite hiển thị trong Terminal.

## Kiểm tra build

```bash
npm run build
npm run preview
```

## Những gì Phase 1 đã có

- React + TypeScript + Vite
- HashRouter phù hợp GitHub Pages
- responsive desktop/mobile
- sidebar desktop
- bottom navigation mobile
- 6 quyển placeholder
- PWA manifest + service worker
- cấu trúc `/public/data/book1` ... `/book6`
- base path tương đối để deploy GitHub Pages thuận lợi

## Chưa có trong Phase 1

- lesson engine
- dữ liệu sách thật
- audio thật
- IndexedDB/Dexie
- quiz/SRS
- backup/restore

Các phần này thuộc Phase sau.
