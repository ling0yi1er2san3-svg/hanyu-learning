HANYU ORIGINAL AUDIO MAPPER V1 - PATCH CỘNG DỒN

Patch này gồm:
- Hỗ trợ audio gốc + TTS song song trong Lesson.
- Bài tập tương tác từ patch trước.
- Mapper Q5/Q6 bằng SHA-256 + xác nhận nghe thủ công.
- Validator mới: verified mapping chỉ hợp lệ nếu file MP3 tồn tại, hash đúng và verificationMethod=user_listen_confirmed.

Cài đặt:
1. Giải nén ZIP.
2. Copy TOÀN BỘ nội dung trong thư mục giải nén vào:
   Downloads\hanyu-learning-v2-github-ready
3. Chọn Replace the files in the destination.
4. Double-click IMPORT_AUDIO_GOC.bat.
5. Làm theo hướng dẫn trên màn hình.
6. Sau khi map xong, chạy PUSH_TO_GITHUB.bat.

Không copy đè public/data-v2 bằng patch này; mapper cập nhật chính dữ liệu hiện có sau khi bạn nghe và xác nhận.
